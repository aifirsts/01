Как выполнялись тесты

Все 17 онлайн-доменов из списка недоступны из песочницы (разрешены только github.com, api.github.com / codeload, registry.npmjs.org, pypi.org, files.pythonhosted.org) — curl вернул 000 для всех. Поэтому тесты прогнаны офлайн, но реальными детекторами:

  • Rebrowser Bot Detector — запущен сам репозиторий (тот же код, что на bot-detector.rebrowser.net).
  • CreepJS — собран из исходников (pnpm build) и запущен локально.
  • FPScanner — собрана библиотека (движок тестов из секции «Fingerprint Scanner» на bot.sannysoft.com) с локальным сервером-приёмником и расшифровкой отпечатка.
  • OverpoweredJS — запущен официальный dist/es5/opjs.min.js (36 компонентов).
  • Класс tls.peet.ws — прямой перехват TLS ClientHello и HTTP/2-фреймов собственным сервером (JA3/JA4, SETTINGS, порядок заголовков).
  • Класс BrowserLeaks — измерения DOM/API напрямую (Canvas, Audio, шрифты, WebRTC, permissions, media queries).

Скриншоты прогонов

Интерпретация

  1. Это «голый» headless-профиль без маскировки — типичная картина агента, управляющего настоящим Chromium через CDP без rebrowser-patches / patchright / camoufox.
  2. Дешевле всего детектится идентичность: HeadlessChrome (UA + sec-ch-ua + userAgentData.brands) и navigator.webdriver = true. Это даёт 100 % детект без поведенческой аналитики.
  3. Сетевой уровень фильтровать бессмысленно — JA4 и HTTP/2 агента неотличимы от браузера пользователя.
  4. Поведенческий слой в этом тесте не имитировался, но по данным FP-Agent (arXiv 2605.01247) именно он решает задачу: Cloudflare в их замере поймал 1 агента из 7, а поведенческий классификатор — всех 7 (paste-ввод вместо нажатий, дискретные прыжки скролла, клики без траектории курсора).
  5. Контейнер добавляет вторичные улики: 1 шрифт, pointer: none, UTC, en-US@posix, 0 медиаустройств, WebGL недоступен, battery «на зарядке» — каждая по отдельности нормальна для VM, в сумме дают устойчивый cloud/headless-профиль.
